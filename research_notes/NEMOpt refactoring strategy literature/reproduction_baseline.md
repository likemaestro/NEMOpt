### Inferences
- Eq. 16 vs. code: at χ-equilibrium (Eq. 14 tested with χ̃^(mn)), ∫∇χ̃^(mn):𝔸:(E+∇χ̃^(rs)) = 0, so the code's symmetric quadratic form equals Eq. 16 to solver precision; the symmetric form is also what the thesis derives (Eq. 4.24/4.25, see Q5). A refactor may use either form, but they differ at round-off/solver-tolerance level, so the golden master should be computed with the form actually used.
- The DR sensitivity has two scale factors that must stay paired: the per-element integral omits the 2 ([NEMOpt-DR.jl:863](../../Domain_Reduction/NEMOpt-DR.jl#L863)) and the final result is doubled ([NEMOpt-DR.jl:934](../../Domain_Reduction/NEMOpt-DR.jl#L934)); the volume gradient instead puts the 2 inside ([NEMOpt-DR_main.jl:149](../../Domain_Reduction/NEMOpt-DR_main.jl#L149)).
- The code computes ∂𝔸/∂F (`Z`) by a hand-written closed form ([NEMOpt.jl:293–295](../../Full_Domain/NEMOpt.jl#L293)). The coordinator's Tensors.jl cross-check covered P and the tangent only ([BENCH](evidence/bench_legacy_kernels.jl)), so Z should get its own test (AD or finite difference of A).

### Gaps
- Eqs. 4–7, 11–13 and 17–18 are derivation steps with no direct code counterpart. Nothing was checked there beyond the end results (Eqs. 10, 16, 19, 20).
- Eqs. 21–22 (energy) are not in the code, so the energy cannot be cross-checked numerically except through P and 𝔸.

### Inferences
- Because the Newton loop always takes one extra correction after the pre-update residual drops below `TOL·Rep_MU` (item 3), the delivered U is typically far more accurate than the nominal tolerance (quadratic convergence). This is likely why forward-difference checks at ε = 1e−6 reach ~1e−8 agreement (Table 2). Moving the check to after the update would loosen the effective tolerance and could degrade FD verification, not just perturb digits.
- Item 3 also matters for published inputs: Table 6 case 1 (F_M = 1.0001·I) gives Rep_MU = 2e−4, i.e. an absolute residual target of 2e−11. That is attainable in double precision only if round-off in F_int stays below it. This is a plausible but unverified hang risk.
- Since `iter` counts function evaluations, the published phrase "every 5 optimization iterations" corresponds in code to "every 5 objective evaluations, counting the setup evaluation at x₀". With MMA02 this differs from MMA outer iterations whenever inner iterations occur.

### Gaps
- Whether MMA02 actually performed inner (non-accepted) iterations in the published runs, and how many, is unknown (no trace files).
- The hang for F_M = 0.975·I is deduced from the code. It was not executed, per the task constraints.

## Q5. Cross-check against Wallin & Tortorelli 2020 and the 2023 thesis; which source is ground truth per ambiguity

### Takeaway
The thesis is accessible and settles most ambiguities in the code's favor: μ/2 energy, (β steepness, ω threshold) naming, H(ρ̃^p) blend argument, and the symmetric sensitivity form. W&T 2020's full text was not accessible (the institutional repositories list no file), so only its abstract-level claims could be checked. For every formula-level ambiguity, the ranking is code first, then thesis, then article. For parameter values of a published case, the article's tables and text are the only source, and where they conflict (filter radius) both values must be tested.

### Cited Findings
- W&T 2020 abstract (verbatim excerpts): "Non-linear homogenization of hyperelastic materials is reviewed and adapted to topology optimization. The homogenization is based on the method of multiscale virtual power in which the unit cell is subjected to either macroscopic deformation gradients or equivalently to Bloch type displacement boundary conditions. A detailed discussion regarding domain symmetry of the unit cell and its effect on uniaxial loading conditions is provided. … solved via the method of moving asymptotes. The adjoint sensitivity analysis considers response functions that quantify both the displacement and incremental displacement. … A periodic filter and thresholding are used … hyperelastic microstructures comprised of Neo-Hookean constituents for maximum load carrying capacity subject to negative Poisson's ratio constraints." Mechanics of Materials 145, 103324 (2020) — [WT-LUP](https://portal.research.lu.se/en/publications/d370cdc9-b861-4aec-8243-38d70b0c42d3).
- Full-text access: the Lund record reports `record_fulltext_access: noFiles` ([WT-LUP](https://portal.research.lu.se/en/publications/d370cdc9-b861-4aec-8243-38d70b0c42d3)); OSTI 1608742 (LLNL-JRNL-770805) lists no accepted-manuscript download, only the publisher link ([WT-OSTI](https://www.osti.gov/pages/biblio/1608742)).

- Thesis Newton algorithm: per load step, assemble, then `while |R| > TOL: solve K·dU = R, U ← U + dU, assemble`. Loop exit is decided on the residual of the latest assembled state, so no correction is applied once that residual is ≤ TOL — [THESIS Algorithm 5.2](https://gcris.iyte.edu.tr/handle/11147/13904). It starts with `R_Norm = Inf`, and `solve` returns both the norm of the current residual and the correction, which is applied unconditionally before the `while R_Norm/Rep_MU > TOL` test. The code therefore always applies one more correction (and one more assembly and factorization) than Algorithm 5.2 per load step ([NEMOpt.jl:387–395](../../Full_Domain/NEMOpt.jl#L387), [NEMOpt.jl:365–367](../../Full_Domain/NEMOpt.jl#L365)).
- Thesis semi-unit cell: point-symmetric fluctuation, zero fluctuation at edge midpoints and center, "nodes will be connected with respect to a vertical axis passing through the center" — [THESIS §6.2](https://gcris.iyte.edu.tr/handle/11147/13904), citing Saavedra Flores & de Souza Neto 2010 and Ohno et al. 2001 (as also cited in [ART §1, refs. 18–20](https://doi.org/10.1016/j.finel.2026.104599)).

### Inferences
- Tolerances. Kernel tests (GM-1 to GM-4) can be near-bitwise under a pinned Manifest. Single-evaluation tests (GM-5 to GM-7) should use ~1e−10 relative on 𝔸_M, because LU vs Cholesky or assembly-order changes alter round-off at about 1e−14 and Newton amplifies this mildly. Trajectory tests (GM-8) are only reproducible bitwise if rounding, continuation keying, MMA variant/options and package versions are all held fixed. Any class-A fix from Q3 needs a deliberate golden-master version bump.
- Acceptance targets (GM-11) should be judged as ranges, e.g. ν within ±0.02 of −0.9008 and κ within ~1–2% plus a check against the HS bound. Initial designs and the filter radius are unrecorded, and the problem is non-convex: the thesis notes different seeds give different optima ([THESIS §7.1.2](https://gcris.iyte.edu.tr/handle/11147/13904)).
- Outputs must be written at full precision (no `round`) in the refactor's test harness. The current files keep only 3–4 digits ([NEMOpt_main.jl:79–86](../../Full_Domain/NEMOpt_main.jl#L79)), which is insufficient for regression comparison.

### Gaps
- No published intermediate quantities (e.g. 𝔸_M of a known design, Newton iteration counts, or per-iteration histories as numbers) exist to anchor GM-5 to GM-8 externally. Those golden masters must be generated from the current code under a pinned environment.
- The linear-response reference (ν = −0.9218) cannot be turned into a test without the absent LEMOpt code or a re-implementation, which would not be a reproduction of the authors' code.
